# Settings and session state

TypeBridge stores everything locally in the browser profile. Browser privacy settings, session restore, storage clearing and eviction can change lifetime. No text is sent to a server.

| Control or state | Storage | Lifetime and tab behavior |
| --- | --- | --- |
| Transliteration on/off | localStorage | Restored on reload, restart and new tabs; each tab writes only this preference. Already-open tabs retain their own current choice. |
| Transliteration shortcut | localStorage | Restored on reload, restart and new tabs. Default is Ctrl+Shift+Space on every platform; existing `default` choices automatically use this binding, including Reset. Saved F7/F8/F9 choices retain Cmd+Shift on macOS and Ctrl+Shift elsewhere; Disabled remains disabled. |
| Saved mapping overrides | localStorage | Restored on reload, restart and new tabs. Unsaved edits in the mapping form are transient. |
| Tab indents | localStorage | Restored on reload, restart and new tabs. |
| Private session | localStorage (`typebridge.autosave.v1`; on = session off / may save, off = private session on) | Restored on reload, restart and new tabs. Same-tab windows sync via prefs CustomEvent; other top-level tabs re-read on the `storage` event and run the session last-save / checkbox path when the preference changes. When on, every document is private: nothing about body, title, Find or Replace is written (no IndexedDB record update for body/history, no reload backup and no emergency copy). A title alone is treated as sensitive, so it is not saved separately either. Settings (transliteration, rules, search options, Focus mode, shortcut) stay persistent regardless. iPhone/Safari and similar browsers can discard a background tab and reload it without `beforeunload`, so the leave-page warning never appears; unsaved text and title are then lost. |
| Per-document private / Autosave | IndexedDB document flag (`private?: boolean`) | Checked Autosave means the document may save; unchecked marks that document private. Survives reload with the document row. Going private offers Keep saved copy / Delete saved copy for a saved document (#257 follow-up); Delete removes the row, change records, and journal/reload backups while the document stays private in memory. While Private session is on, the checkbox stays off and disabled. |
| Match case and Regex | Separate localStorage keys | Restored on reload, restart and new tabs; an already-open tab retains its current values. Each preference is written independently. |
| Find and Replace text/history | Document fields in IndexedDB; gated document change log, journal and reload backup | Restored with that document, including across tabs/restarts. Each field has its own Undo/Redo history. Private edits stay in memory; toggling privacy leaves fields/history visible. Viewers/non-owners keep their own search only in memory. Legacy independent query/replacement sessionStorage keys are removed. |
| Current document selection | sessionStorage hint | Restored in the same tab where available. Duplicate tabs may inherit the hint. |
| Documents and undo/redo history | IndexedDB | Committed documents and history survive reload and browser restart subject to browser storage. Revision checks prevent stale writes; conflicts create copies. |
| Emergency recovery | temporary localStorage journal and sessionStorage reload snapshot | Only while writes are allowed (`mayWrite` / not `privateNow`); see architecture for recovery, limitations and conflict handling. |
| Focus mode | localStorage | On/off is restored on reload, new tabs and browser restart. Restoring Focus mode focuses the editor after its document loads and preserves the saved Normal-mode dimensions. Existing tabs keep their current layout. Blocked storage falls back to Normal mode without a warning. |
| Settings panel open or closed | in memory | The Settings button opens one side panel with the transliteration shortcut and rules, Private session, Tab indents and related controls ([#123](https://github.com/vchernoy/typebridge/issues/123), [#257](https://github.com/vchernoy/typebridge/issues/257)). Per-document Autosave lives in the editor chrome, not Settings. The panel is closed again after reload, and hidden in Focus mode on `/editor.html`. |
| Editor resize | localStorage | Resize by dragging the grip drawn on the editor's bottom-right corner, or Tab to it (it is a button named "Resize editor") and use the arrow keys. It stays on the editor's corner as the editor changes size, in Normal and Focus mode, and the editor can shrink to 160 × 96 px ([#70](https://github.com/vchernoy/typebridge/issues/70)). The grip is meant for iPhone Safari, which never shows a native grip (not yet verified on a physical device); its touch target extends below the editor so that inside it covers only the bottom padding, not text; Normal and Focus mode each have their own saved size (`typebridge.editor.size.v1` and `typebridge.editor.focusSize.v1`), restored on reload, restart and new tabs whenever the page is in that mode, subject to responsive min/max constraints; resizing in one mode never changes the other's ([#120](https://github.com/vchernoy/typebridge/issues/120)). Resizing behaves the same in Focus mode (the corner follows the pointer although the editor is centered, the width may exceed Focus mode's default 900 px, same minimums). Without a saved Focus size, Focus mode uses its default layout. The drawn grip replaces native textarea resizing on the main editor. |
| Appearance | localStorage | System (default), Light or Dark. System follows OS changes; a manual choice survives reload in this browser. Existing tabs keep their selection. Blocked storage keeps the current page choice but may lose it on reload; failures are reported separately from document saves. Reset settings restores System. |
| Editor selection, caret and scroll | sessionStorage, per document | Restored after the document loads in the same tab, including when switching documents. Startup restores the position once after enabling the editor and applying Focus layout. Offsets clamp to current text and Unicode code-point boundaries; scroll clamps to the current layout. Independent new tabs start at the beginning; duplicated tabs/session restore may inherit a copy. Blocked or corrupt metadata is ignored. Event-driven writes are debounced by 250 ms; document-switch saves and pagehide and hidden-page events flush immediately. Restoration first flushes any captured outgoing position. The position helper does not register beforeunload; unsaved-document warnings remain managed separately. Abrupt termination can lose the latest position metadata. After a successful document deletion its position key is removed and later events cannot recreate it. Successful startup lists and complete list refreshes prune obsolete keys in this window/view namespace while keeping the current unsaved document. This stores offsets only, never text or Undo history. |
| Page scroll, Find match selection, imported file picker | in memory/browser managed | Not promised across reload. Undo/redo history is part of the committed document. |

Storage access can be blocked or exhausted. The editor remains usable, and a Find settings warning indicates when state cannot be saved or restored. If the transliteration or Private session preference cannot be saved, a separate warning beside the save status names it; a later successful document save does not clear it, and it clears only when that preference is saved. Search fields continue to work for the current page even when storage fails. Browser-provided form restoration is not treated as persistent configuration.
